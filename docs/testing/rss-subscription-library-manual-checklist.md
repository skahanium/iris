## 1. 数据与升级

- [ ] 从不含 `063` 的现有数据库升级；笔记、会话、设置、MCP 配置和 Vault 选择不变。
- [ ] 新数据库建立 `feed_sources`、`feed_items`、`feed_items_fts` 和 trigger。
- [ ] 开发环境执行 down 后只移除 RSS 表，不影响其他应用状态。
- [ ] 切换 Vault 后订阅源、文章、未读、收藏和归档保持一致。
- [ ] 未执行「保存为笔记」时，Vault 内没有新增或修改的 `.md`。
- [ ] 订阅 500 个源、保存 100,000 篇合成文章后重启可恢复。

## 2. 格式与内容转换

- [ ] RSS 2.0、RSS 1.0/RDF、Atom HTML/XHTML、JSON Feed 可添加和阅读。
- [ ] 只有 summary 的条目可读；只有标题/链接的条目安全降级。
- [ ] 标题、列表、引用、代码、表格、链接和图片转换为合法 Markdown。
- [ ] 相对链接正确转为安全 HTTPS 绝对链接。
- [ ] script/style/iframe/form/event handler/`javascript:` 不出现在 DOM。
- [ ] DTD/ENTITY Feed 被拒绝，旧内容仍可读，错误文案不含响应正文。
- [ ] 超大、损坏或非 UTF-8 内容不崩溃；degraded 条目有明确提示。
- [ ] 转换器升级重转不改变已读、收藏、归档、收到时间和文章 ID。

## 3. 同步生命周期

- [ ] 输入直接 Feed URL 可发现；输入站点 URL 可发现 alternate Feed。
- [ ] 多候选由用户选择，不自动订阅全部。
- [ ] 首次同步默认历史已读；选择「历史也设为未读」后进入收件箱。
- [ ] 后续新增项目为未读；同 GUID 更新正文但不重置用户状态。
- [ ] ETag/Last-Modified 生效；304 不制造文章或未读。
- [ ] 手动单源/全部刷新有进度、成功、失败状态。
- [ ] 同源重复刷新只执行一次；应用重启后可再次同步。
- [ ] 断网、超时、429、500、DNS、证书失败进入退避，旧文章可离线阅读。
- [ ] 暂停源不自动同步；重新启用后恢复。
- [ ] 上游删除文章不删除本地副本。

## 4. 阅读状态与收件箱

- [ ] 收件箱只包含未读且未归档项目。
- [ ] 已读/未读、收藏、归档可独立组合和撤销。
- [ ] 收藏后归档仍在收藏视图；取消归档不改变收藏。
- [ ] 打开预览不立即标已读；正文可见或发生阅读动作后按设置标记。
- [ ] 批量已读只作用于确认时冻结的当前筛选，回执数量正确。
- [ ] 今日使用本地时区零点，跨午夜刷新正确。
- [ ] 退订「保留文章」不丢内容；「删除文章」显示数量并二次确认。

## 5. 搜索与容量

- [ ] 标题、作者、正文和中文短语可搜索；结果来源明确为订阅。
- [ ] 按 source/view 筛选；清空查询恢复此前视图。
- [ ] 搜索不触发联网，不混入 Vault 笔记，不调用 Agent。
- [ ] 特殊 FTS 字符、超长查询和空查询安全处理，无 SQL 错误泄漏。
- [ ] 100,000 篇合成文章下列表/搜索/详情达到性能基线。
- [ ] 快速切换查询时迟到响应不覆盖当前结果。

## 7. 键盘、读屏与动效

- [ ] Tab 顺序符合视觉顺序；所有图标按钮有中文 accessible name。
- [ ] `j/k/o/Enter/m/s/e/r` 生效；输入框和输入法 composition 中不误触发。
- [ ] 打开文章后焦点移到标题；返回列表恢复原条目焦点。
- [ ] 未读不只靠颜色；同步状态和批量结果由 live region 适量播报。
- [ ] VoiceOver、NVDA 或 Orca 至少完成对应平台主流程。
- [ ] `prefers-reduced-motion` 下无位移动画，功能不受影响。
- [ ] 200% 缩放和高对比设置下焦点环、文字、按钮仍可辨识。

## 8. 网络、隐私与日志

- [ ] HTTP、userinfo、localhost、loopback、private、link-local、metadata URL 被拒绝。
- [ ] DNS 同时返回公共/私网地址时整体拒绝。
- [ ] 每次重定向重新校验；超过 5 跳或循环安全失败。
- [ ] Feed 5 MiB、发现页/OPML 上限生效；流中超限也能停止。
- [ ] 「使用系统代理」开关立即影响新同步，无需重启。
- [ ] 远程图片默认零请求；手动加载只允许 HTTPS、lazy、no-referrer。
- [ ] 外链通过系统浏览器打开，非 HTTPS 协议不能调用 opener。
- [ ] 日志、错误和事件不含 Feed URL、文章 URL、标题、正文、OPML、header 或源载荷。

## 9. OPML 与保存为笔记

- [ ] 嵌套 OPML 导入保留 folder path；重复 URL 幂等合并。
- [ ] OPML 导出不包含 ETag、错误、阅读状态、内部 ID 或凭据。
- [ ] 导出后清空测试资料库再导入，订阅关系和分组往返一致。
- [ ] 保存为笔记前明确选择目录/文件名；同名不覆盖。
- [ ] 保存成功后生成合法 UTF-8 Markdown，并通过正常文档索引回执打开。
- [ ] Feed 更新不修改已保存笔记；删除任一侧不级联另一侧。
- [ ] 涉密 Vault/笔记边界沿用现有策略，不从普通订阅绕过 classified 约束。
