# v1.2.19 自适应工作区人工验收清单

> 在自动化测试通过后执行。测试记录不得包含笔记正文、绝对 vault 路径、API Key、Token、加密密码、模型原始错误或工具原始输出。
>
> 施工顺序、自动化门禁与文件边界见 [v1.2.19 实施计划](../superpowers/plans/2026-07-31-v1.2.19-adaptive-workspace.md)；本清单对应其 Task 8，并按计划中的交付判定结案。

## 测试准备

- [ ] 使用包含根目录笔记、至少三级文件夹、空文件夹、锁定笔记、图片、视频和 100+ Markdown 文件的临时 vault。
- [ ] 至少打开 3 个文档 Tab，其中一个为 dirty、一个包含 50+ 标题、一个约 50KB。
- [ ] 准备一段包含标题、列表、表格、代码块、引用和 citation 的长 Agent 回答。
- [ ] 记录应用构建类型、系统版本、显示缩放和窗口内容尺寸，但不记录 vault 绝对路径。

## 默认写作态

- [ ] 启动后仍为 Markdown 文档主区 + Agent 右侧侧车，不出现永久文件三栏。
- [ ] 正文消费现有 `--prose-measure`，标题、正文和 Outline 留白与 v1.2.18 基线一致。
- [ ] 标题栏文件入口位于 traffic safe area 之后、Tab rail 之前；新建按钮、更多菜单和窗口控制无错位。
- [ ] 无打开 Tab 时，文件入口在 WorkspaceEmpty 仍可用；不会恢复欢迎工作台或 hero。

## 浮动文件导航

- [ ] 点击标题栏文件入口或按 `Ctrl/Cmd+\\` 打开左侧浮动抽屉；正文和 Agent 宽度不发生变化。
- [ ] 再次点击入口、按 Esc 或明确返回编辑区会关闭抽屉，焦点回到合理位置。
- [ ] 普通动效下抽屉仅以轻量淡入/淡出打开、关闭，不横向滑动、不推动正文；关闭期间不可交互，退出结束后卸载。
- [ ] `prefers-reduced-motion` 下抽屉立即打开/关闭，不保留动画或位移动画。
- [ ] 抽屉是上下分层浏览器：上层只显示根目录与文件夹（含直属 Markdown 数），下层只显示选中文件夹的直属文件；两层绝不混排，空文件夹可见，reserved roots 不可见。
- [ ] 文件夹或文件过多时，上下区分别显示细滚动条并可独立滚动；列表不会撑出抽屉、裁切底部条目或带动正文滚动。
- [ ] 标题行仅居中显示“笔记库”，不展示图钉或快捷键提示。上层工具条仅有当前目录新建文件夹、排序、全部展开/折叠；下层工具条仅有媒体显示、搜索、排序、新建笔记，所有 icon 控件都有可读名称与 tooltip。
- [ ] 文件夹名称只选择目录，箭头和左右键才展开/收起；文件夹图标随展开状态切换，嵌套行的细树形导轨连续、对齐且在亮/暗主题下可辨。选中目录和当前文件使用弱 brand tint 与细 marker，不出现厚选中框或紫色分类色。
- [ ] 从标签页、搜索结果切换当前文档后，父目录自动选择并展开；手动选择目录时下层立即切换。删除选中目录后回退到最近存在父目录，最终为根目录。
- [ ] 点击“全部折叠”后目录保持折叠；切换到另一篇文档时再自动显露新的祖先路径。
- [ ] 下层默认只显示 Markdown；眼睛按钮能切换直属图片、PDF、视频。搜索只匹配当前目录当前可见范围，切换目录、清空或 Esc 后收起。
- [ ] 两层排序相互独立：文件夹按名称/直属笔记数，文件按名称/更新时间；相同值稳定按名称。中间分隔线可拖动、方向键每次 5%、双击恢复 45/55，范围 25%–70%，亮/暗主题可辨。
- [ ] 连续打开多个文件时抽屉保持打开，Tab、活动路径、编辑器正文和状态栏同步更新。
- [ ] hover/focus 后打开文档无空白帧；快速连续点击时最终显示最后一次用户选择。
- [ ] Markdown、锁定笔记、图片和视频分别进入正确的 note/media 路由。

## 文件树键盘与读屏

- [ ] 文件入口、固定按钮、树行和操作菜单均有可读名称、tooltip 与可见焦点。
- [ ] ↑/↓ 遍历可见行；← 收起或移动到父级；→ 展开或进入第一个子项；Enter 打开。
- [ ] Shift+F10 或菜单键打开当前行操作；Esc 先关闭菜单/对话框，再关闭抽屉。
- [ ] 文件夹 `aria-expanded`、tree/treeitem 层级和当前项语义可被读屏器正确宣布。
- [ ] 从快捷键打开导航后聚焦当前文件；关闭后焦点返回文件入口。

## 常用文件操作

- [ ] 在根目录与选定文件夹新建笔记，路径无覆盖，创建后打开并保持导航器可用。
- [ ] 新建空文件夹后立即出现在正确父级，展开状态不丢失。
- [ ] 重命名普通/打开/dirty 文档后，磁盘、Tab、活动路径、最近笔记、导航树与 editor surface 一致。
- [ ] 移动普通/打开/dirty 文档或文件夹后，wiki/backlink 影响与现有管理中心语义一致。
- [ ] 锁定前 flush dirty 正文；锁定/解锁后编辑器与导航行状态一致。
- [ ] 删除文案为“移入回收站”，确认后可在管理中心恢复；轻量导航中没有永久删除。
- [ ] 取消重命名、移动或删除后不改变磁盘、Tab、展开集合或当前编辑状态。
- [ ] 索引降级时明确显示弱警示，Markdown 文件动作成功不被回滚。

## 固定导航与宽度预算

- [ ] 在足够宽窗口固定导航后形成“导航 + 文档 + Agent”；正文仍达到保护宽度。
- [ ] 拉宽 Agent 或缩窄窗口导致预算不足时，固定导航自动退回浮动抽屉，不关闭也不压窄正文。
- [ ] 重新扩大窗口时，仅当导航仍打开且固定偏好存在才恢复固定；已关闭导航不会自动打开。
- [ ] 浏览器缩放或系统根字号变化后预算重新计算，不出现重叠、裁切或无限 resize 抖动。

## Agent 侧车与主区阅读

- [ ] Agent 侧车可在 `25rem–45rem` 范围内调整，目标宽度约 `30rem`；拖动不会突破正文保护宽度。
- [ ] 空间不足时侧车退为可见入口；不会继续把正文压窄，也不会因 resize 自动创建 Tab 或切换当前文档。
- [ ] 点击“展开阅读”后 Agent 占据主工作区，标题栏仍清楚表达当前文档工作集，但不出现 Agent Tab。
- [ ] 主区消息、表格、代码、过程流、citation、授权边界和 Composer 居中且不超过文档级行宽。
- [ ] 返回文档后恢复原文档、光标、选区、滚动位置、undo/redo 和 dirty 状态。
- [ ] 点击任一文档 Tab、Quick Open 结果或新建笔记会先退出 Agent 主区，再打开目标。
- [ ] Agent 主区状态不跨应用重启恢复。

## Agent 稳定状态

- [ ] 在 Composer 有未发送草稿、mention、图片时往返主区，所有输入保持。
- [ ] streaming Run 期间往返不取消、重复或重启 Run；滚动跟随与手动停留行为保持。
- [ ] 工具确认、恢复、联网失败、能力降级和错误状态在两种 presentation 中语义一致。
- [ ] 历史会话切换、新建对话、消息选择、复制/导出/插入在主区正常工作。
- [ ] classified 会话往返不持久化敏感历史、不改变解锁超时、不泄露路径或授权。

## 文档选区与 Agent 临时关联

- [ ] 未选中文字时文档与 Agent 完全解耦；普通文档选中非空文字后，Agent 可见时立即显示可移除的「当前选区」候选。
- [ ] 拖动或键盘扩大/缩小选区时候选实时替换；取消选择、选区折叠、切换文档或隐藏 Agent 后立即解除，不残留上一段选区。
- [ ] Agent 重新显示时只根据仍存在的当前非空选区重新计算；新建/切换会话不制造额外引用，候选发送成功后清除，发送失败保留供重试。
- [ ] 锁定普通文档仍可选择并引用已提交内容；未保存文档显示保存提示并阻止发送；classified 文档不进入此候选通道。
- [ ] 候选预览仅存在于当前界面，不进入请求、会话、日志或持久化；发送请求只包含已校验的路径、内容 hash 和 UTF-8 范围。
- [ ] 编辑器右键菜单仅有剪切、复制、粘贴、全选；锁定/只读时仅复制、全选，不出现“AI · 选区”或发送/改写/翻译等动作。
- [ ] Composer 上下文条使用弱底色、2px 品牌前缘和 ghost 移除按钮，不显示第二输入框式整圈描边；候选更新不闪烁，`prefers-reduced-motion` 下立即切换。
- [ ] `@`/`#` 候选支持多词标题、全半角空格、NBSP、中文括号、斜杠、空文件夹和键盘/IME；选定后节点整体可删除，复制粘贴及手工 `@名称` 不恢复授权。
- [ ] 普通域与 classified Composer 往返切换时草稿和 mention 不串域；发送显示自然名称，后台范围与 UTF-16 位置保持准确。

## 禅模式与 Overlay

- [ ] 进入禅模式隐藏导航与 Agent；退出后恢复进入前的打开/固定/侧车意图。
- [ ] Quick Open、全库搜索、管理中心、确认对话框优先于导航器处理 Esc。
- [ ] 管理中心 `Ctrl/Cmd+Shift+E` 仍打开完整库管理，不与轻量导航快捷键冲突。
- [ ] 文件抽屉与管理中心不会同时争夺焦点或出现双重文件动作对话框。

## 分辨率与主题矩阵

- [ ] `1024px`：文档优先，文件导航为浮动；Agent 使用折叠入口/主区阅读，无三栏挤压。
- [ ] `1366px`：文档保护宽度成立；Agent 侧车或折叠行为与预算一致。
- [ ] `1440px`：默认写作、浮动导航和 Agent 主区往返稳定。
- [ ] `1920px`：允许固定导航；三块区域均无裁切，正文仍保持预期行宽。
- [ ] 亮色与暗色主题下检查边框、brand marker、阴影、焦点和文字对比。
- [ ] `prefers-reduced-motion` 下无抽屉位移和正文宽度动画；普通模式无明显布局抖动。

## 平台标题栏

- [ ] Windows：文件入口与最小化/最大化/关闭按钮可点击，drag region 不吞点击。
- [ ] macOS：原生 traffic lights safe area 保持，窗口化/全屏切换后入口和 Tab 不重叠。
- [ ] Tab 溢出时活动 Tab、更多菜单、文件入口与新建按钮都可达。

## 失败态与降级（Task 8 新增）

- [ ] catalog 加载失败时浮动抽屉保留壳层并显示可重试的错误，不关闭当前文档或 Agent。
- [ ] 重命名/移动失败时已开始迁移的路径回滚一致（磁盘、Tab、活动路径不出现半迁移状态）。
- [ ] 索引降级显示弱警示，Markdown 文件动作成功不被回滚。
- [ ] 保存失败（dirty flush 拦截）时新建/重命名/移动/删除动作被屏障阻止并有明确提示。
- [ ] 用户取消重命名、移动或删除确认后，磁盘、Tab、展开集合与当前编辑状态不变。
