# Agent 对话流式显示验收

本轮改造将会话身份、权威正文、本地播放、Markdown 块和滚动分别管理，并通过稳定标识连接。前端逻辑回归与真实桌面性能验收分别记录。浏览器回放和 jsdom 通过不代表 Tauri WebKit / WebView2 已达到帧预算。

## 已实现的行为

- 首次回执补齐 session、Run、turn 元数据时保留会话视图与用户行；明确新建、切换会话或安全域时重置视图。
- 完整安全正文保留在消息及现有 payload 存储；本地播放只在气泡内部推进。远端结束进入追赶显示，提供“立即显示全部”；发送下一题时同批补齐上一题。
- durable/presentation 完成顺序、较短历史补载不会让全文闪现后回退。resetEpoch 清除旧播放任务；取消保留已经显示的安全前缀。离屏再返回恢复可见进度。
- 实际帧时间驱动显示，初始约 4 视觉行/秒、积压时连续加速至 20 行/秒；换行和小增量共用预算，字素完整，后台恢复不补时间欠账。减少动态效果模式直接显示。
- 流式与完成共用正文容器。块按源范围标识，标题、列表、表格、引用定义和围栏采用连续解析；代码高亮延后，保留容器、字体和行高。
- 消息行只有一个父级；长正文通过现有 TanStack Virtual 的块/行窗口控制 DOM。移除聊天正文 32k/80k 显示截断，消息及代码复制读取完整内容。
- 阅读锚点 hook 统一滚动写入。临时底部空间至少 96px，并补足用户问题置顶所需空间；用户上滚优先，键盘、触摸和滚动条均可退出/恢复跟随。

## 失败回归证据

新增测试先复现后修正的错误包括：回执改变用户 key；durable completed 提前覆盖显示前缀；标题漏字；松散列表重复；连续空行突发；组合 emoji 分裂；窄视口字素永久停住；60/120Hz 速度不一致；短回答无法置顶；连续 10px 上滚不能脱离；正文完成和跨 8k 阈值重新挂载；长列表项按 inline 节点被错误拆分；引用定义污染代码及表格；未换行的结束围栏提前冻结；空代码显示围栏；终态离屏重播或取消前缀丢失；短历史补载清屏；键盘到底不能恢复跟随；终态先于最后高度通知导致漏跟随；程序滚动被浏览器夹限后误判用户上滚；引用网址内的同名文字误定位成正文；CRLF 标题和代码块漏渲染；嵌套虚拟器跨阈值启用时默认初始化滚动到 0。

回归入口包含 `assistant-stream-lifecycle`、`use-assistant-answer-reveal`、`streaming-message-body`、`streaming-markdown-splitter`、`streaming-line-fit`、`use-conversation-reading-anchor`、`ai-message-list-real-virtualizer-regression` 和 `ai-message-list-playback-window` 等受影响测试。

## 合成回放

启动 `npm run dev`，打开：

入口只位于测试目录，不进入正式应用入口，不调用模型或 Tauri IPC，不读写笔记。挂载生产 `AiMessageList`，同时加载生产全局和 Markdown 样式，固定视口高度；可选 1k、8k、32k、80k、200k，混合 Markdown、单段正文或代码，并调整宽度。

先完成一轮，再发送下一轮；追赶期可点击“立即显示全部”。点击“测试上滚”会触发合成上滚并开始记录阅读位置偏移；顶部“测试显示全部”调用气泡的生产按钮，方便在长文回放中执行同一操作。长文可勾选“到达后自动显示全部”，避免自动化工具为定位气泡按钮额外滚动。记录持续到呈现完成/取消后 1 秒，包含收尾布局与观察器回调；同时记录首次脱离时间和附近数值轨迹。另需手动覆盖触控板微小滚动、触摸、键盘、滚动条和调整窗口大小。

页面展示帧数、React render p95、浏览器支持时的 Long Task 数量、正文容器替换次数、最大 DOM 数量、上滚锚点偏移以及 ResizeObserver/被观察节点数量。“导出数值记录”只导出合成回放的数字与阶段，不包含真实会话内容。

**指标边界：** React Profiler 的 render 时间不包括所有 layout effect、浏览器布局和绘制。不能把该值直接当作整条流式链路主线程 p95；正式门槛需要固定设备下的浏览器/桌面性能轨迹。未执行“测试上滚”时 maxAnchorDrift=0 不构成锚点验收证据。

## 桌面执行

Windows 复用现有独立 Tauri WebDriver 环境（`tauri-driver`、匹配的 Edge WebDriver、已构建 Iris exe）。保持上述 Vite 服务运行，执行：

```sh
npm run test:desktop:windows -- --stream-replay
```

该模式使用隔离应用目录，先进入合成流入口，检查默认回放完成且正文无重建，并输出数字摘要；不执行笔记持久化场景。该入口属于新增待真机验证的路径。macOS 需在真实 Tauri WebKit 窗口中执行同一受控回放并采集时间线；Codex 内置浏览器不能替代该验收。

## 尚待桌面确认的门槛

- 非预期阅读锚点偏移 ≤2px；用户上滚后的下一帧停止自动运动。
- 正常完成没有正文重建、空白帧、回退或重复块。
- 60/120Hz 同输入轨迹的显示进度差 ≤5%（时间轴单元回归已覆盖，设备差异需真机复核）。
- 主线程流式处理 p95：60Hz <8ms、120Hz <4ms；无本链路引起的 ≥50ms 长任务。
- 本地发送反馈 <100ms；不计模型响应时间。
- 200k 正文完整可访问、复制完整，DOM 数量随可见范围控制，完成不展开全部历史块。

超长活动块持续出现语法结构变化时，解析器仍可能需要重新处理整个活动语义块；单个超大表格单元格目前保留行边界，尚未进一步拆分单元格。这些输入必须单独记录成本，不能用普通段落的结果替代。
