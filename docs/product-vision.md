# Iris 产品愿景

> 状态：产品形态与内容本体的愿景原则。**不构成版本排期或施工计划**；排期唯一来源是 [ROADMAP.md](../ROADMAP.md)。  
> 与 [Agent 架构定义](./agent-architecture.md)、[agent-harness](../agent-harness/README.md) 的关系：本文只规定内容与呈现的投影方式，不改变 Run、权限、证据与诊断合同。当前阶段优先 agent 重构，本文供后续前端形态决策对照。

---

## 一、产品定位

Iris 是**本地优先的 AI 原生 Markdown 笔记**：用户的知识、写作、与 AI 的交互收束在**同一个 Markdown 世界**里。

「AI 原生」的判据不是有没有聊天侧栏，而是：**AI 是否在思考、写作、资料使用的关键路径里**，且产品形态与任务同构——而不是让用户离开正文去「问一下」。

---

## 二、单一本体：对话即笔记

- **一切内容都是 Markdown 文档**：手动笔记、与 AI 的交互记录、自测题、讨论与闲聊留档。
- **对话不是第二类系统**：AI 交互是文档内的块；历史即文档本身；版本快照天然可回溯。
- **不设常驻对话侧栏**，不存在与笔记平行的会话史。闲聊 = 新建一篇《杂谈》在其中提问；讨论长在材料旁；出题长在自测笔记里。

创建时不需要选择「写作模式 / 学习模式」。库里只有 Markdown 文档，用法差异体现在文档内容与块结构上，不体现在第二套类型系统上。

---

## 三、交互入口

- 无独立聊天窗。通过 `/` 命令或快捷键发起 AI 交互：有选区时锚定选区，无选区时在光标处。
- AI 回答插入文档，成为**可编辑正文**；执行过程为特殊折叠块。用户可继续手改、链接、删除。
- 对材料的动作（解释、讨论、出题、润色、扩写）从同一入口发出，交互天然带材料锚点（当前文档、选区、`@` 引用、必要时联网）。

---

## 四、过程与安全边界

| 层级 | 是否入文档 |
| ---- | ---------- |
| 用户提问、AI 回答 | ✅ 正文 |
| 过程脱敏摘要、安全来源列表 | ✅ 特殊折叠块 |
| 原始思维链 | ❌ |
| 工具参数、工具原始输出 | ❌（留运行审计域；文档内最多按 run 引用跳转） |

涉密域内容不写入普通笔记。上述边界与现有安全与持久化约束一致，不因「对话即笔记」而放宽。

文档示意：

```markdown
论行政处罚的正当程序

一、正当程序的规范依据
《行政处罚法》第 5 条要求……

> [!ask] 那听证程序的适用范围怎么理解？
> 可分法定听证与裁量听证……（即正文，可编辑）

> [!process] 过程（折叠）
> 检索本地 2 条 · 联网核对新规 1 页
> - 法条：处罚法第 5 条（本地）
> - 网页：某司法解释（2026-03）
```

## 五、呈现合同：落盘单调，呈现多态

- **存储**：用户手写与 AI 写入都以高级 Markdown 为限（GFM + 现有受控扩展）。不为用户发明新语法。
- **呈现**：渲染层可超越 Markdown 表达，提供流式与动效体验。呈现策略**不写入 Markdown**（与 GIF 裁切规则同源：Markdown 不写入展示策略）。

| 内容 | 落盘 | 呈现 |
| ---- | ---- | ---- |
| 手动文本 | 高级 Markdown | 常规排版 |
| AI 文本 | 同左 | 流式字素 reveal、稳定段落节奏 |
| 图片 / SVG | 图片引用或受控片段 | 主题自适应、轻量放大、布局无抖动 |
| 删改 | 文档新版本 | 差异过渡动画，可中断 |
| 过程块 | 脱敏摘要 | 平滑折叠 / 展开 |

动效硬约束：`prefers-reduced-motion` 全量降级；动画仅使用 `transform` / `opacity`；不得以动画掩盖加载错误或内容缺失。

---

## 六、明确不做

- 常驻对话侧栏、第二套会话史
- 「研习」等第二文档类型；专用试卷表单与错题库子系统（试卷即笔记）
- 将展示策略、动效参数写入 Markdown
- 原始思维链或工具原始输出写入用户笔记
- 通用插件式交互组件市场（与产品边界一致）

---

## 七、典型使用形态（示意）

| 场景 | 形态 |
| ---- | ---- |
| 写法律/法治文章 | 主面写；选区润色、扩写、插依据 |
| 讨论要义、时政 | 在笔记中 `/ask`，回答与过程块长在材料旁；必要时联网 |
| 闲聊、漫谈 | 新建《杂谈》文档，提问即对话；想留就是笔记本身 |
| 明确要求出考题 | `/ask 出 5 道题`，生成/长在自测笔记；作答后再让 AI 判、讲解 |
| 回看历史 | 打开那篇笔记；版本可回溯；库内搜索覆盖一切 |
