## 1. 已收回的控制面

- `ExecutionEnvelope` 只冻结 effect、授权范围、风险、能力与预算；不冻结电影、天气、写作等解题策略。
- 明确联网/核实、URL 与高利害当前事实是硬验证信号；日常时效与其他已授权联网任务为 `WebPreferred`。工具面存在时进入同一个有界循环，由模型决定是否调用。

## 2. 连续对话与最终答复合同

会话仅持久化四个有界记忆字段：当前目标、约束/最新更正、已完成且经 Host/工具确认的结果、未解决事项。最近 12 对完整 user/assistant 消息保持原样；旧 assistant 文字和历史引用只能帮助指代，不能证明当前事实。

当上下文溢出时，压缩必须保留显式目标、偏好、更正、完成与待办；压缩失败不得阻断回答。最近 24 条提交消息原样保留；覆盖范围前移时，既有四字段摘要在同一 Run 内最多触发一次无工具模型压缩（字段最多 500 字、总计最多 1,500 字），计入 8 次模型预算，并以确定性提取兜底。长 Direct 仅允许冻结为两次模型、零工具的明确合法形状，并复用这一公共准备；任何未覆盖的历史区间必须在 Provider 上下文中显式标记，不得沉默地被视为已摘要。当前确定性压测验证投影与预算合同，不把固定 mock 当作真实模型语义能力。

普通回答不走结构化终局。`WebRequired` 或已使用 Web/外部证据的自然正文由 Host 绑定本 Run 的受控来源；模型可提供精确标记，但缺少标记不得丢弃已有合格正文。只有来源不存在、权限或状态损坏才拒绝终态；`SourceGroupFallback` 仅兼容读取旧记录，不能满足新回答的事实来源要求。
