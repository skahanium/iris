## 接口

**输入**：后续用户指令、取消、确认反馈。

**输出**：带修订号的待处理输入，或停止信号。

| 字段             | 逻辑类型                     | 说明                                     |
| ---------------- | ---------------------------- | ---------------------------------------- |
| Run 身份         | 引用 `K01` 输出的请求身份    | 修订挂在该 Run 上，不新建请求身份        |
| 修订号           | 单调递增序号                 | 随每个请求、工具调用与原生搜索子请求传递 |
| 修订内容         | 用户显式提交的文本与引用     | 只有用户显式提交的内容构成修订           |
| 与前一修订的关系 | 追加要求、纠正、替换         | 供 `C07` 决定当前约束如何覆盖            |
| 吸收点           | 模型／工具交接安全点         | 修订在此之前的交接完成后才生效           |
| 取消范围         | 本次调用、当前批次或整个 Run | 决定停止信号传播到哪里                   |

**本次选择（架构 §3 M1）**：用户在运行中补充要求，先形成输入修订，在模型／工具交接安全点吸收；正在发生的外部调用可请求取消，其迟到结果保留为旧修订观察，不自动成为新答案；确认前目标或内容发生变化，使旧确认失效；对于不能撤销的已执行动作，只报告事实，不假装回滚。

**取消信号必须到达的边界**：provider、工具调度与写盘前提交检查。取消只覆盖“尚未开始的副作用”，不承诺撤销已提交的写入。

**修订号是 `K01` 定义的身份字段之一**，本文件定义它如何递增与如何被消费，不重新定义字段清单。

## 状态转换

**输入修订**：

| 状态   | 含义                           | 合法转换                                                       |
| ------ | ------------------------------ | -------------------------------------------------------------- |
| 已记录 | 用户已提交，尚未到达交接点     | → 已吸收（到达安全点）；→ 被取代（更晚的修订在同一运行中提交） |
| 已吸收 | 已进入本轮上下文，成为当前约束 | → 被取代（又出现更新的修订）                                   |
| 被取代 | 仍是历史事实，不再是当前约束   | 终态；不得回退为“已吸收”                                       |

**取消**：

| 状态     | 含义                               | 合法转换                                               |
| -------- | ---------------------------------- | ------------------------------------------------------ |
| 未请求   | 正常运行                           | → 已请求（用户取消或明确权限拒绝）                     |
| 已请求   | 停止信号已生成，尚未确认各边界停止 | → 已停止（各边界停止）；→ 结果未知（副作用回执未取得） |
| 已停止   | 不再启动新副作用                   | 终态                                                   |
| 结果未知 | 已发起或可能已发起的写入回执未知   | 核实回执后 → 已停止；不得直接重试                      |

**确认失效**：确认前目标或内容变化使旧确认失效（确认身份与有效期的完整定义见 [K05](./K05-authorization-and-confirmation.md)）。失效是转换，不是删除：旧确认保留为历史事实。

## 不变量

1. **旧修订产生的未发布答案不能覆盖新要求。** 未发布候选在修订到来后失去发布资格。
2. **取消后不启动新副作用。** 停止信号覆盖 provider 调用、工具派发与写盘前提交检查。
3. **迟到结果只作为旧修订观察保留**，不自动成为新答案。
4. **确认前目标或内容变化使旧确认失效**；失效的确认不得再用于执行。
5. **不能撤销的已执行动作只报告事实**，不假装回滚；回执未知时先核实，不盲目重试。
6. **修订只改变当前约束，不改写历史事实**：旧地区、旧版本的材料仍是旧观察，不能被摘要改称新证据。
7. **修订号单调递增且随请求传递**，任何边界都不得用本地序号替代它。

## 异常处理

| 失败类别               | 表现                             | 是否可恢复                 | 反馈给谁                                     | 不得继续的情形               |
| ---------------------- | -------------------------------- | -------------------------- | -------------------------------------------- | ---------------------------- |
| 修订到达时正在外部调用 | 调用已发出，结果返回时修订已生效 | 该结果保留为旧修订观察     | 内部执行轨迹；`C25` 依据当前修订决定发布内容 | 不得把旧观察并入新修订的答案 |
| 取消未获确认           | 停止信号已发，边界未回报停止     | 可恢复：等待或核实回执     | 用户与诊断入口                               | 不得假定写入未发生           |
| 回执未知的写入         | 取消与写入竞争                   | 必须先核实回执             | `C06` 执行回执、`C26` 记录                   | 不得因重试造成重复变更       |
| 不可撤销的已执行动作   | 动作已提交，无法回退             | 不可撤销                   | 用户看到事实说明                             | 不得声称已回滚               |
| 修订与确认冲突         | 修订改变了已确认的目标或内容     | 使旧确认失效并要求重新确认 | 用户；`C05`／`C06` 边界                      | 不得按旧确认执行             |
| 修订无法吸收           | 交接点不可用或 Run 已结束        | 转为新请求                 | 用户与 `K01` 边界                            | 不得就地改写已建立的请求身份 |

用户可见措辞由 `K15` 定义；本文件只规定内部事实与停止条件。

## 消费方

| 消费方 | 消费的字段                                 | 用途                                                                   |
| ------ | ------------------------------------------ | ---------------------------------------------------------------------- |
| `C03`  | 修订号、修订内容、关系、取消范围、吸收点   | 形成待处理输入或停止信号，并在安全点吸收                               |
| `C07`  | 修订号、与前一修订的关系                   | 装配本轮上下文：为稳定指令与最新纠正保留空间，并给出覆盖或缺口说明     |
| `C14`  | 修订号、停止信号、确认失效事实             | 决定下一步是继续、修正、澄清还是结束；不给无信息增益的相同错误无限重试 |
| `C25`  | 修订号、未发布候选的发布资格、生命周期状态 | 不发布已失效版本的最终答案，并按 `K15` 表达最终结果                    |

## 验证

按 [acceptance-matrix.md](../testing/acceptance-matrix.md) 的证据用途分类，本合同需要：

1. **`V03` 局部机械不变量**：取消后不产生新的副作用启动；确认前目标变化使旧确认失效；旧修订的未发布候选失去发布资格。违例用例必须能在正确实现中被发现。
2. **`V04` 跨组件交接与生产入口证据**：以生产入口验证修订号确实到达 provider、工具调度与写盘前提交检查，并覆盖“调用进行中到达修订”“取消与写入竞争”“回执未知”等异常路径。
3. **`V06` 语义质量证据**：用户纠正之后是否真的被承接，属于语义质量，需要真实模型场景与明确判据，并由人工抽检确认；单一话术通过不能证明广泛可用。

「运行中追加／修改指令的具体交互」仍是未决问题（`Q16`）；本文件不据此发明交互判据，缺口登记在 `G05`。证据记录按 `V08` 绑定对象指纹与当前适用性。
