# 共享合同索引

<!-- iris:object README-CONTRACTS kind=rules file=true -->

本目录是 18 份共享接口与合同的正式定义位置。合同只规定**跨模块的接口、状态转换、不变量与异常**；模块责任在 `modules/`，工具合同在 `tools/`，链路顺序在 `flows/`。

| 合同  | 名称                       | 责任组件 | 消费方                                   |
| ----- | -------------------------- | -------- | ---------------------------------------- |
| `K01` | 请求身份与引用绑定         | `C01`    | `C01`、`C03`、`C07`、`C22`               |
| `K02` | Run 生命周期与任务结果分离 | `C02`    | `C02`、`C25`、`C27`                      |
| `K03` | 输入修订与取消             | `C03`    | `C03`、`C07`、`C14`、`C25`               |
| `K04` | 供应商能力状态与续轮保真   | `C10`    | `C10`、`C11`、`C12`、`C20`               |
| `K05` | 授权范围与冻结确认         | `C04`    | `C04`、`C05`、`C06`、`C17`、`C20`、`C24` |
| `K06` | 统一预算账本               | `C13`    | `C12`、`C13`、`C15`、`C17`、`C20`、`C21` |
| `K07` | 上下文装配与裁剪边界       | `C07`    | `C07`、`C08`、`C11`                      |
| `K08` | 压缩覆盖与长期记忆条目     | `C08`    | `C08`、`C09`                             |
| `K09` | 联网授权与查询外发         | `C04`    | `C04`、`C19`、`C20`、`C21`、`C15`        |
| `K10` | 工具面版本与派发观察       | `C16`    | `C16`、`C17`、`C14`                      |
| `K11` | 双路搜索协调结果           | `C20`    | `C20`、`C10`、`C18`、`C22`、`C25`        |
| `K12` | 原生搜索受控子请求         | `C20`    | `C20`、`C11`、`C12`                      |
| `K13` | 网页读取窗口与完整性       | `C21`    | `C21`、`C22`、`C15`                      |
| `K14` | 证据身份、来源与支持关系   | `C22`    | `C22`、`C07`、`C23`、`C25`               |
| `K15` | 交付结果与用户可见表达     | `C25`    | `C25`、`C23`、`C14`                      |
| `K16` | 验证报告与可恢复错误反馈   | `C23`    | `C23`、`C14`、`C17`、`C24`               |
| `K17` | 审计事件与诊断查询         | `C26`    | `C26`、`C27`、`C11`、`C20`、`C21`        |
| `K18` | MCP 传输与外部工具边界     | `C18`    | `C18`、`C16`、`C20`、`C21`               |

**多消费者共享一个合同是合法的**：合同只定义一次，消费方各自引用；检查器据此核对 `applies_to` 与 `consumes` 关系。

### README-CONTRACTS 目录索引
