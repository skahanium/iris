## 接口

**输入**：用户消息、选区、目标文档、明确操作。四项都来自用户显式提交，不接受由上下文推断补全。

**输出**：请求身份与材料引用。

请求身份的字段构成如下。字段名的中文表述是设计层逻辑名称，不是已经存在的 Rust 类型或 IPC 字段。

| 字段         | 逻辑类型              | 说明                                                                                       |
| ------------ | --------------------- | ------------------------------------------------------------------------------------------ |
| 会话身份     | 不透明引用            | 会话身份不进入隐式请求上下文；只有用户明确提交的引用与一次性动作快照可以进入本次请求       |
| Vault 身份   | 规范化路径与库身份    | 用于区分同名路径与跨库引用；词法路径含符号链接组件时，无法完成独立身份解析即在副作用前拒绝 |
| 文档版本     | 版本标识与内容哈希    | 目标文档的版本与内容身份，取不到即无法完成绑定                                             |
| 选区／范围   | UTF-8 字节区间        | 作用对象可以是字词、单句或一段；范围边界按 UTF-8 编码给出，不使用依赖前端字符计数的偏移    |
| 明确操作     | 有限动作枚举          | 本请求要求的操作类别，不承载领域预判                                                       |
| 幂等键       | 调用身份的一部分      | 用于把重试与迟到结果关联回同一请求身份，不与授权判定混为一个字段                           |
| 既有授权事实 | 引用 `K05` 的判定结果 | 只记录用户已经显式给出、且仍有效的事实，不由本次请求自行生成                               |

**显式引用必须携带可复验的内容身份**：路径 + 哈希 + UTF-8 范围三项齐全。三项缺一即不构成显式引用，只能作为待解析的线索。

出站请求的关联字段（Run ID、输入修订号、父调用 ID、尝试 ID）由 `K01` 定义其身份语义，工具调用另记工具面版本；`K10` 定义工具面版本本身，`K17` 定义这些字段如何进入安全记录。本文件不复制 `K10`、`K17` 的正文。

**语义意图保持可修订**：身份字段描述“这次请求是谁、指向什么材料”，不描述“模型应当如何理解”。语义意图不进身份字段，因此可以在同一请求身份内被后续修订取代，而不必重新建立请求身份。

## 状态转换

请求身份本身是一个持久身份，不引入自己的状态机。本文件定义的是**材料引用的可用性**。

| 引用可用性 | 含义                                   | 进入方式             |
| ---------- | -------------------------------------- | -------------------- |
| 当前       | 内容身份与所引用文档的当前版本一致     | 绑定成功             |
| 过期       | 所引用文档的版本或内容哈希已变化       | 版本或哈希复核不一致 |
| 无法复验   | 目标文档已删除、授权已撤回或存储不可读 | 复核时目标不可达     |

**合法转换**：当前 → 过期（文档被改写）；当前 → 无法复验（文档删除或授权撤回）；过期与无法复验在同一次重新绑定后可以回到当前。

**禁止转换**：过期或无法复验的引用不得通过投影写回“当前”。运行中输入只能形成带修订号的待处理输入（见 `K03`），不得就地改写已建立的请求身份。

## 不变量

1. **显式授权事实不由模型推断。** 外部网页、MCP 返回值与检索到的笔记是资料，不是新的用户指令；其中要求改权限、泄露数据或调用其他工具的文字不能改变授权事实。
2. **迟到结果不能冒充最新请求。** 旧修订产生的结果必须携带其原始请求身份与修订号；投影与最终发布都不得把它当作最新请求的答案。
3. **显式引用必须携带可复验的内容身份。** 路径 + 哈希 + UTF-8 范围缺一，即不是显式引用。
4. **绑定的四个对象是会话、Vault、文档版本与选区**，四者必须在同一请求身份内一致；其中任一项无法确定时不建立请求身份。
5. **身份一旦建立即不被投影改写。** 上下文装配、摘要覆盖、证据登记与最终交付读到的必须是同一套身份字段。
6. **语义意图与身份字段分离**：语义意图可修订，身份字段只能重新绑定。

## 异常处理

| 失败类别               | 表现                                         | 是否可恢复                               | 反馈给谁                                                | 不得继续的情形                |
| ---------------------- | -------------------------------------------- | ---------------------------------------- | ------------------------------------------------------- | ----------------------------- |
| 输入不足以构成请求身份 | 缺少目标文档、选区范围无法确定或操作类别未知 | 可恢复：用户补齐后重新提交               | 用户，并说明缺哪一项                                    | 不得建立 Run 后靠模型猜测补全 |
| 文档版本变化           | 引用的内容哈希与当前版本不一致               | 可恢复：重新绑定或由确认边界使旧确认失效 | 用户与 `C05`、`C06` 边界                                | 不得按旧版本执行写入          |
| 显式引用缺少内容身份   | 只有路径或只有片段，没有哈希与范围           | 视为待解析线索，不作为显式引用           | 内部执行轨迹                                            | 不得把线索当作已授权材料送模  |
| 存储或身份解析不可读   | Vault 身份无法解析、符号链接路径无法独立解析 | 不可自动恢复                             | `C26`、`C27` 记录缺口                                   | 不得在副作用前继续            |
| 迟到结果到达           | 旧修订的外部调用返回                         | 作为旧修订观察保留                       | 内部轨迹；是否需要改变交付由 `C25` 依据当前任务结果判断 | 不得自动成为新答案            |

## 消费方

| 消费方 | 消费的字段                                                         | 用途                                     |
| ------ | ------------------------------------------------------------------ | ---------------------------------------- |
| `C01`  | 全部字段                                                           | 建立并持久化请求身份与材料引用           |
| `C03`  | 请求身份、修订号                                                   | 在安全点吸收后续输入修订；不重写身份字段 |
| `C07`  | 会话身份、Vault 身份、文档版本、选区／范围、既有授权事实、材料引用 | 装配本轮上下文并给出裁剪、过期与覆盖说明 |
| `C22`  | 内容身份（路径 + 哈希 + UTF-8 范围）、引用可用性                   | 登记来源身份、阅读范围与支持关系         |

`K01` 是共享合同：以上消费方引用本文件，不复制正文。`C07` 与 `C22` 在 [catalog.mjs](../catalog.mjs) 中以 `consumes` 声明对本合同的消费。

## 验证

按 [acceptance-matrix.md](../testing/acceptance-matrix.md) 的证据用途分类，本合同需要：

1. **`V03` 局部机械不变量**：显式引用三项内容身份缺一即被拒绝；过期引用不得被投影写回当前；本地确定性正例与违例用例成对登记在 [evidence.md](../testing/evidence.md) 的登记表里，违例用例必须在正确实现中能被发现。
2. **`V04` 跨组件交接与生产入口证据**：以生产入口验证修订号与请求身份确实到达上下文装配、网关与工具派发边界，并覆盖绑定失败的异常路径。仅证明两个替身函数被调用不构成该证据。
3. **`V07` 诊断可定位性**：一次绑定失败要能在诊断中定位到“在哪里发现、由哪个组件产生”，并把身份字段与语义材料的完整性分开表达。

本合同不自行发明判据；证据记录按 `V08` 绑定对象指纹与当前适用性。
