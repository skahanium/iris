## 4. 更新规则

- 当前命名测试失败时立即降级对应状态。
- 生产复现与测试结论冲突时记录事故并将能力标为部分实现或已知缺陷。
- 旧测试若只固化被撤回方向，必须随替代阶段删除，不能改名后继续保留。
- 真实 Provider 状态必须带日期、模型、配置 hash 和授权；fixture 永远不能升级为生产质量证据。
- 每个 HR 阶段完成时只更新本阶段相关行，不重写历史事故。
