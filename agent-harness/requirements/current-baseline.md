### Q02 设置写入冲突：两个入口的 MCP 搜索候选语义不一致

### Q03 评测空分母被记为满分

- **已确认事实**：`verdict.rs` 的 `ratio_bps` 在分母为 0 时返回 `10000`；`aggregate_capacity_scorecard` 据此计算召回、引用与约束门。当前实现先汇总原子分子分母，并非逐用例百分比取平均，`atoms` 完全为空也会报错。
- **不能推出**：「每个无要求用例都会拉高混合评测分数」。缺陷是某个维度总分母为零却仍可标为满分通过。
- **影响边界**：`E01`、`E03`；对应架构定义 `F02`。
- **所需证据**：区分「适用／未覆盖／通过」并显示实际分母的判据；零分母维度不得作为质量证据放行（`V01`）。
- **覆盖**：已由聚合负例覆盖；历史 v1.2.15 报告仍为旧口径。

### Q04 流式终止原因丢失（Chat Completions 分支）

- **已确认事实**：`model_gateway/streaming.rs` 的 Chat Completions 流式分支没有消费 `choices[0].finish_reason`，正常返回及一处尾缓冲早退写死 `stop`；`length` 等异常终止不能可靠到达 `FinalAnswerIntegrity`。
- **不能推出**：所有协议都忽略终止原因——同文件 Anthropic 状态机已有停止原因处理，Responses 走独立路径。
- **影响边界**：`C11`、`C23`、`C14`；对应架构定义 `F03`。
- **所需证据**：覆盖正常结束、长度截断、工具结束、尾事件与缺失终止事件的协议测试（`V05`）。
