# D06 校准整体行为及可选委派

本工作包依据 [Agent 架构定义](../../docs/agent-architecture.md) §10.3 的 **D5** 依赖单元建立。D5 是架构定义中的最后一个依赖单元，直接对应版本单位会让“文档体系的重建”与“另一轮 Harness 重编号”混在一起，因此本体系把它登记为施工工作包 `D06`，不改动其内容边界。

<!-- iris:object D06 kind=rules owner=C15 file=true -->

## 一、前置条件

| 前置                     | 状态要求                                                |
| ------------------------ | ------------------------------------------------------- |
| `D04` 双路搜索完整链路   | 已完成并留下生产入口证据                                |
| `D05` 文档任务与最终交付 | 已完成并留下候选差异、内容保持、写入回执证据            |
| `E03` 评分与校准         | 已修正 `Q03` 的空分母表达，机械／组合／语义评价分开报告 |
| `V06` 语义质量证据       | 判据、抽样规则与人工校准记录齐备                        |

## 二、改动范围

- 验证父子预算与来源：子运行使用 `from_child_policy` 的工具额度，并从父级总资源中显式分配（`K06`）。
- 评价委派收益：单 agent／子 agent 对照需要说明模型、任务、总成本、耗时与上下文条件，不能只比较回答长度。
- 修正子任务接口合同：`context_hint` 与 `max_rounds` 必须被消费或被明确拒绝；取消固定 50／75 的伪置信概率（`Q06`）。
- 子任务网页核验必须具备获准的 `web_fetch`（`Q07`）。
- 完整诊断与真实任务评价应当**贯穿各单元**，不推迟到这里才开始（`V07`、`V08`）。

## 三、回归证据

- 委派对照记录：任务、模型、总成本、耗时、上下文条件、来源与未解决问题。
- 父子预算归属记录：父级总消耗、子级分配、重叠与遗漏均为 0。
- 子任务报告来源绑定：报告结论只能引用本子运行实际取得的证据身份（`K14`）。
- 首试成功率、可恢复案例最终完成率、额外耗时与调用成本、错误提示误报、越权或重复副作用的分别报告（架构 §8.6）。

## 四、回退条件

- 委派收益无法证明时，保留为**受限可选能力**，不作为普通任务默认路径。
- 子任务报告无法绑定来源或无法回溯用量时，停止扩大委派范围，回到 `D04`／`D05` 的证据口径。
- 预算调整若破坏旧 Run 存档读取（`Q13`），回退到受控配置并保留原策略版本。

## 五、不作出的承诺

- 不设新的发布分数，不设容错百分比门槛。
- 不把多 agent 设为默认架构；也不因受限实现的失败否定整个思路。
- 对照实验是建议，不是施工安排：换模型可能同时改变协议适配、工具调用习惯与输出结构。
- 能力保持是新循环相对薄工具循环的**内部**对比，不证明绝对档位。

### D06 正式定义

## 合同要点

- **前置**：`D04`、`D05`、`V06`、`E03`。
- **改动范围**：父子预算与来源、子任务接口合同（`context_hint`／`max_rounds`／伪置信度）、子任务网页核验、委派收益对照。
- **证据**：委派对照记录（任务、模型、总成本、耗时、上下文条件）、父子预算归属记录、报告来源绑定、分项报告。
- **回退**：委派收益无法证明时保留为受限可选能力；报告无法绑定来源时停止扩大委派范围。
- **关闭**：`Q06`、`Q07`、`Q19` 所需的对照与校准结论。
- **不得发生**：把多 agent 设为默认架构；用受限实现的失败否定整个思路。
