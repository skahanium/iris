# 01. 权威边界与长期不变量

> **文档状态**：现行
> **文档类型**：长期规范
> **事实基线**：2026-09-01，审计起点 `e30f47d1`

本文只定义任何 Harness 实现都必须遵守的长期合同，不表示目标已经实现。当前事实见文档 02，实施状态见附录 A。

## 1. 产品与数据权威

- Iris 是本地优先的 Markdown 笔记应用，不建设任意代码执行环境、工具市场或与笔记无关的通用 Agent 平台。
- 用户 `.md` 文件是笔记知识最权威来源；SQLite 笔记索引必须可重建，AI 会话和外部证据只是应用状态。
- 未经用户明确确认不得修改 Markdown；模型推断、Web 内容和历史回答不得反向成为用户事实。
- `ROADMAP.md` 是版本排期唯一来源；`ARCHITECTURE.md` 只记录已经部署的结构。

## 2. 受约束的模型自主性

- 模型可以理解任务、制定有限步骤、选择本轮已暴露工具、调整搜索方向、比较材料和组织回答。
- 模型不能扩大权限、修改预算、伪造工具结果、决定 Run 终态、声明写入已提交或把历史来源冒充本轮来源。
- Host 不以电影、天气、金融等领域规则代替模型的语义判断；确定性规则只用于授权、风险、时效下限、数据身份和副作用。
- 模型能力差异只能在 Gateway 协议适配中处理，核心不得按 Provider 或模型名称分叉。

## 3. Run 生命周期与内容所有权

- `client_request_id` 是持久化幂等键：同 ID、同指纹重放原 Run；同 ID、不同指纹安全冲突。
- 同一普通会话同时最多有一个活动顶层 Run；子任务不得形成竞争真相源。
- 最终助手消息和必要绑定提交成功后才能进入 `Completed`，随后才能投影完成事件。
- 正文、过程、工具生命周期、引用和错误必须携带同一 Run 身份；迟到事件不得污染新 Run。
- 恢复只消费持久化事实；旧失败 Run、Provider 调用和副作用不得被静默重放。

## 4. 权限与工具表面

- Web 开关、classified/local-only 状态、显式材料和用户授权是能力边界的唯一来源。
- Intake 冻结 capability 和工具表面；工具展示、`capabilities_read`、执行门禁和恢复必须消费同一快照。
- 模型可以多轮调用已授权工具，但每次调用都必须重新经过目录、参数、权限、预算、取消和审计门禁。
- 本地自动检索内容不得进入 Web query、URL、日志、错误或外部 Provider 参数。
- 工具结果是不可信数据，永远不能提升为系统指令。

## 5. 通用预算与停止

- Direct、普通 ToolLoop、Delegated 和 DurableApply 使用同一冻结 `RunBudgetPolicy` 事实源。
- 总模型轮次、总工具调用、分类工具调用、token、时间、重复调用和无进展轮次都必须有 Host 硬上限。
- 精确相同的成功调用不得重复；相同失败调用只能有限重试。
- 无进展或探索预算耗尽时应保留一次无工具综合机会，而不是默认把已有可用材料变成红色终态错误。
- 只有权限、安全、持久化、严格证据或确定性写入合同无法满足时才失败关闭。

## 6. 来源与最终化

- 继续复用一个 evidence ledger，不新增平行来源表。
- 来源必须属于当前 Run、未失效且可定位；旧 Run、会话展示标签和数据库裸 ID 不能参与本轮来源解析。
- `ProvenancePolicy` 是 `W/E/L/M` 来源语法和 Run 所有权的唯一解释器；其他模块不得重复匹配 ID。
- 普通回答允许可定位的当前 Run 受控引用；现代消息只投影最终选择的 evidence，旧来源组仅作缺失选择字段时的读取兼容。Harness 不宣称已经完成自由文本语义蕴含验证。
- 结构化最终提交只用于明确 CitationCheck、高风险当前事实或其他确定性合同，不得成为普通回答的普遍失败点。

## 7. 澄清、确认与写入

- 普通缺参、偏好询问和范围确认使用自然 assistant 回答并正常结束当前 Run；下一条用户消息由会话上下文承接。
- 只有写入确认、外部授权或必须绑定原事务的不可重复人工决定可以暂停同一 Run。
- 写入必须冻结目标、操作顺序、参数、基线 hash、预期 hash 和失效时间；用户只授权所见变更集。
- 确认后只能执行冻结操作；验证阶段只允许限定目标的有界只读工具，任何新增写入都必须重新确认。

## 8. 隐私、安全与简化纪律

- API Key、Token、笔记正文、解密密码、Provider 原始输出和敏感路径不得进入日志、事件或评测报告。
- 网络访问必须使用 HTTPS，并通过 SSRF、重定向、大小、类型和超时检查。
- 新抽象只有在同阶段删除对应旧分支、旧测试和旧文档后才能进入主干。
- 禁止第二 Run engine、第二工具循环、第二 provider registry、第二 evidence store、长期双写和领域专用平行状态机。
- 兼容只留在读取边界；新 Run 不再写入被退出的领域规划合同。
