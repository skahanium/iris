# 附录 C：未来能力提案

**状态：Deferred。** 本附录保存值得继续观察、但不应进入当前可靠性主干的能力。它们不是承诺，也不能反向推动预建实体或抽象；任何条目只有完成重新立项流程后才能移出本附录。

## 进入主干的共同门槛

任一提案重新立项前必须同时满足：

1. 有明确、重复出现的个人项目使用场景，而非平台想象；
2. `README` 与 5 份核心文档定义的 P0/P1 可靠性契约已经通过；
3. 有离线评测集、隐私边界、失败降级和可删除方案；
4. 能复用现有 Run、工具目录、证据和消息真相源；
5. 维护成本与 Iris 个人项目规模相称；
6. 若改变版本排期，先进入 `ROADMAP.md`，而不是直接写入本目录主干。

## 1. 自由文本语义证据校验（EVID-003，Deferred）

可研究 LLM/NLI 对“回答句是否被来源支持”的辅助判断，但只作为影子实验：

- 不产生用户可见 VERIFIED 标签；
- 不参与默认完成条件或 CI 硬门禁；
- 必须与人工标注集比较准确率、漏报和误报；
- 输出可解释的候选警告，不覆盖确定性 citation binding；
- 模型不可用或结果冲突时，稳定降级为 uncalibrated。

本轮只保留“没有注册规则就不能进入 VERIFIED”的 fail-closed 门，不实现通用自由文本语义校验，也不把它纳入完成标准。实际引入结构化业务工具时，再按该工具注册字段、单位、来源与时效规则；只有在固定评测上证明误导风险显著下降、成本与延迟可接受后，才讨论自由文本判断的有限生产用途。

## 2. 跨会话语义记忆

当前只保留会话摘要和用户确认的少量偏好。未来若确有需求，可评估语义召回，但必须先解决：

- 用户可见、可编辑、可删除的记忆清单；
- 记忆来源、作用域、时效和冲突处理；
- 敏感信息识别与默认不记忆；
- Markdown 删除/修改后的失效传播；
- 召回错误不会被当作用户事实。

不得先建设向量库、记忆评分中心或后台自动人格画像，再寻找用途。

## 3. 六类之外的垂直扩展

时间、天气、新闻、金融、影视和体育的最小只读能力已进入 `ROADMAP.md`，但作为核心缺陷收口后的独立能力增强施工，范围和规则见附录 D。这一决定不授权继续扩张成“万能数据层”。

购物、旅行、医疗诊断、法律判断、自动交易和个性化投资建议继续 Deferred。每个领域如需立项，必须独立证明：

- 存在重复的 Iris 个人项目使用场景；
- 数据来源许可与 AGPL-3.0 分发边界清楚；
- 有确定性 schema、时效含义、单位/地域规则和离线降级；
- 错误不会导致健康、法律、财务或外部交易风险；
- 不要求新建通用 provider 市场、自动交易执行器或第二证据仓库。

## 4. 原生搜索提供方与浏览器操作

原生搜索 API 可在当前 Web 适配器确有质量或稳定性瓶颈时评估。浏览器操作风险更高，需单独明确：

- 可访问域名和动作白名单；
- 登录态、下载、提交表单和付款的确认边界；
- 页面提示注入隔离；
- 可重放性与审计记录；
- 失败时不产生外部副作用。

这不是当前 Harness 可靠性重构的自然延伸。

## 5. 工具生态与多 Agent

第三方插件协议、动态工具安装、通用子 Agent 编排和任意代码执行均超出 Iris 的个人笔记产品边界。除非 `ROADMAP.md` 明确改变产品定位，否则保持不建设。

当前代码中的遗留名称不构成保留这些平台能力的理由；没有真实生产调用链的入口应优先删除或隐藏。
